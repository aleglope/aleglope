## How I work

- **Model the problem before expanding the implementation:** clarify users, data ownership, constraints and acceptance criteria.
- **Use AI assistance for scoped tasks:** research, implementation and review, with project instructions and explicit boundaries. Specialized review tooling has supported work on translation sessions and database migrations.
- **Check behavior and failure paths:** typed contracts, focused tests, integration checks and human review, with delivery limits recorded per project.
